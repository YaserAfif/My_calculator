# دفتر حساب‌کت برای آیفون

## امکانات
- ثبت اسم، قیمت و تاریخ
- جمع خودکار تجمعی برای هر ردیف و مجموع کل
- جست‌وجوی نام و حذف ردیف
- خروجی واقعی Excel با پسوند `.xlsx` و خروجی CSV
- ذخیره در مرورگر همان دستگاه
- پشتیبان‌گیری و بازیابی فایل JSON
- رابط فارسی/دری و قابل استفاده روی موبایل
- قابلیت نصب به شکل PWA پس از نشر روی HTTPS

## مهم: نصب روی آیفون
برای دکمه «Add to Home Screen» باید این فایل‌ها روی یک آدرس HTTPS قرار گیرند؛ فایل ZIP به تنهایی اپلیکیشن iOS نصب‌شدنی نیست.

### روش ساده با GitHub Pages
1. در GitHub یک مخزن (Repository) جدید بساز.
2. فایل‌های داخل این پوشه را مستقیم در ریشه مخزن بارگذاری کن: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
3. در Settings → Pages، انتشار از شاخه `main` و پوشه `/(root)` را فعال کن.
4. پس از فعال‌شدن، لینک HTTPS سایت را در Safari آیفون باز کن.
5. دکمه Share را بزن و **Add to Home Screen** را انتخاب کن؛ سپس Add را بزن.

## نگهداری داده‌ها
اطلاعات در localStorage مرورگر همان دستگاه ذخیره می‌شود و به‌صورت خودکار با دستگاه دیگر همگام نمی‌شود. پاک‌کردن داده‌های Safari، استفاده از مرورگر دیگر یا تغییر دستگاه می‌تواند باعث از دست‌رفتن داده‌ها شود. به همین دلیل از دکمه «گرفتن نسخه پشتیبان» استفاده و فایل JSON را در Files یا iCloud Drive نگهداری کن. خروجی Excel را نیز مرتب بگیر.

## حریم خصوصی
این نسخه بدون حساب کاربری و بدون سرور پایگاه داده کار می‌کند؛ رکوردها به سرور فرستاده نمی‌شوند. اگر می‌خواهی چند کارمند از دستگاه‌های مختلف یک دفتر مشترک داشته باشند، نسخه دارای پایگاه داده و ورود امن لازم است.

## نکته
خروجی Excel با فایل `.xlsx` ساخته می‌شود و در Microsoft Excel، Numbers و برنامه‌های سازگار قابل بازشدن است.

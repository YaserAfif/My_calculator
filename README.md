# دفتر حسابات — نسخه ۱۰ (روزمره)

نسخه ۱۰ ادامه مستقیم نسخه ۹ است. کلیدهای ذخیره‌سازی `hesabket.records.v1` و `hesabket.accounts.v3` و `hesabket.settings.v3` و `hesabket.currencies.v8` ثابت مانده‌اند. قبل از جایگزینی، از بخش تنظیمات **پشتیبان JSON** بگیرید.

## تغییرات

- دکمه «نصب برنامه» در سربرگ و تنظیمات؛ در مرورگرهای پشتیبانی‌شده پنجره نصب PWA و در Safari آیفون آموزش افزودن به صفحهٔ اصلی. نصب نیازمند HTTPS (مانند GitHub Pages) است.
- ایجاد خودکار ۳ حساب سیستمی «خزانه»، «مصارف» و «پرداخت نشده» در نصب نو و برای حساب‌های قبلی، بدون حذف اطلاعات موجود. این سه حساب حذف نمی‌شوند.
- صفحه‌بندی ۲۰ یا ۵۰ ردیف برای حساب‌ها، خلاصه حساب‌ها، راپور مشتری، راپور بخش و دفتر معاملات. خروجی‌های کامل بر اساس حساب و فیلتر تهیه می‌شوند، حتی اگر فقط ۲۰ ردیف روی صفحه باشد.
- نسخه برنامه `10.0.0` در تنظیمات و «تماس با ما» با واتساپ `https://wa.me/93711648583`.
- حذف خروجی CSV از منوها؛ خروجی واقعی XLSX با عنوان، زمینه رنگی، فرمت عدد، فریز سطر عنوان، فیلتر و تنظیمات چاپ. فقط برای حساب/ارز/بخش و بازهٔ انتخابی.
- PDF/چاپ: صفحهٔ اختصاصی و خوانا برای صورت‌حساب، با سرصفحه، تاریخ و خلاصه مالی، که می‌توان آن را از مسیر چاپ مرورگر به PDF ذخیره کرد. در Safari آیفون گزینه اشتراک‌گذاریِ پیش‌نمایش چاپ اجازه ذخیره PDF می‌دهد. **PDF مستقیماً دانلود نمی‌شود و از قابلیت Print to PDF دستگاه استفاده می‌کند.**
- طراحی و لینک سایت یاسر عفیف در واترمارک حفظ شده است.

## استقرار

۱. پشتیبان بگیرید. ۲. تمام فایل‌های همین پوشه را در ریشه مخزن GitHub Pages جایگزین کنید. ۳. پس از انتشار، برنامه را کاملاً بسته و دوباره باز کنید تا service worker نسخه ۱۰ فعال شود. ۴. نصب PWA را از URL اصلی سایت HTTPS امتحان کنید.

**محدودیت:** اطلاعات در مرورگر همان دستگاه ذخیره می‌شود؛ نصب برنامه روی دستگاه دوم اطلاعات را خودکار انتقال نمی‌دهد. از فایل پشتیبان برای جابه‌جایی اطلاعات استفاده کنید.

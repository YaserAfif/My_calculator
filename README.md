# دفتر حسابات — نسخه 24.1.0 (ساختار یکپارچه)

این بسته همان نسخهٔ ۲۴ دفتر حسابات است. منطق داده‌ها، فرم‌ها، جستجو، صرافی، حواله‌ها و ثبت‌های حسابداری تغییر نکرده است؛ تنها ساختار فایل‌ها یکپارچه شده است.

## فایل‌های اصلی

- `index.html`: ساختار صفحه بدون CSS یا JavaScript داخلی
- `style.css`: **تنها فایل CSS**، شامل تمام استایل‌های نسخه‌های قبلی و صفحهٔ اصلی
- `app.js`: **تنها فایل JavaScript پروژه**، شامل لایسنس، منطق اصلی و تمام اسکریپت‌های v13 تا v24 و کد Service Worker
- `manifest.webmanifest` و `icon.svg` / `icon-192.png` / `icon-512.png`: نصب به‌صورت PWA و آیکن‌ها
- `COPYRIGHT.txt`: حق نشر

## راه‌اندازی

تمام فایل‌های موجود در بسته را بدون تغییر نام در پوشهٔ اصلی سایت یا مخزن GitHub Pages قرار دهید. هیچ فایل `v13.js` یا `v13.css` قدیمی نباید از `index.html` بارگذاری شود.

این نسخه همان کلیدهای `localStorage` قبلی را استفاده می‌کند و به‌صورت پیش‌فرض اطلاعات حساب‌های موجود را حذف یا تغییر نمی‌دهد. پیش از جایگزینی فایل‌ها از داده‌ها بکاپ بگیرید. برای پیشگیری از تداخل نسخهٔ کش‌شده، بعد از آپلود صفحه را یک بار به‌صورت Hard Refresh باز کنید.

برای استفادهٔ آفلاین، `app.js` با همان آدرس در نقش Service Worker هم اجرا می‌شود و فایل‌های اصلی را کش می‌کند. فایل `sw.js` جداگانه دیگر لازم نیست. اتصال و اعتبارسنجی آنلاین لایسنس همچنان از سرویس Supabase استفاده می‌کند؛ کتابخانهٔ عمومی آن از CDN بارگذاری می‌شود و برای ورود اولیه نیاز به اینترنت دارد.

## موارد حفظ‌شده در نسخه ۲۴

- منوی آیکن‌دار قابل باز و بسته شدن
- ارزهای مستقل «گرفت» و «طلب» روزنامچه
- محاسبهٔ دوطرفه در صرافی، حوالهٔ وارده و صادره
- منطق مفاد حواله و مفاد صراف در حوالهٔ وارده با شیوهٔ «درک»
- شمارهٔ نسخهٔ 24.1.0 در تنظیمات

طراحی و توسعه: یاسر عفیف

## تغییرات نسخه 24.1.0

- عنوان «بستن فهرست» کوچک‌تر و نام بخش‌های فهرست هنگام بازبودن خوانا شده‌اند.
- محاسبهٔ حواله‌های وارده و صادره از هر دو طرف (مبلغ اصلی یا مقدار مبادله) با نرخ و ضرب/تقسیم ثابت برقرار است.
- در حوالهٔ واردهٔ حساب صراف، فیلد «شماره حواله صادره صراف» به‌صورت مرجع مستقل نمایش داده می‌شود، در اسناد ثبت می‌گردد و هنگام ویرایش بازخوانی می‌شود.
- مفاد صراف به‌صورت پیش‌فرض اتومات محاسبه می‌شود؛ مبلغ دستی را می‌توان وارد کرد و با دکمهٔ «خودکار» دوباره محاسبه نمود.
- مفاد حسابداری با مبالغ نهایی ذخیره می‌شود؛ اسناد و حساب‌های گذشته دست‌کاری نشده‌اند.

برای اجرای نسخه جدید پس از انتشار، یک‌بار صفحه را تازه‌سازی کنید؛ Service Worker کش نسخهٔ جدید را جایگزین می‌کند. پیش از جایگزینی فایل‌ها، از اطلاعات بکاپ بگیرید.

# دفتر حسابات — نسخه ۹ (اصلاح روزنامچه و درک)

این نسخه ادامهٔ مستقیم نسخهٔ ۸ است و از همان کلیدهای اطلاعاتی در localStorage استفاده می‌کند؛ اطلاعات حساب‌ها و معاملات قبلی حذف یا بازنویسی نمی‌شوند.

## امکانات و اصلاحات

- **روزنامچهٔ واکنش‌گرا:** حساب در سطر نخست؛ گرفت، انتخاب ارز رنگی و طلب در سطر دوم؛ سپس تاریخ، توضیحات و سه گزینهٔ کم‌حجم «خزانه / بدون مدرک / درک».
- **پیش‌فرض:** خزانه. با انتخاب درک، انتخاب حساب مقابل باز می‌شود؛ حساب مقابل نمی‌تواند همان حساب نخست باشد.
- **منطق درک:** برای «گرفت» بدهی حساب منتخب به اندازهٔ مبلغ بیشتر و بدهی حساب مقابل به همان مقدار کمتر می‌شود؛ برای «طلب» برعکس. دو ثبت هم‌ارزِ مرتبط با یک شناسهٔ انتقال ساخته می‌شوند. انتقال درک اثری بر خزانه ندارد. ویرایش یا حذف یک طرف انتقال، ثبت مقابل را نیز به‌روزرسانی یا حذف می‌کند.
- **چندارزی:** ارزهای موجود و ارزهای افزوده‌شده در روزنامچه، داشبورد، حساب‌ها، راپور و خروجی‌های همان ارز در دسترس‌اند. مجموع مانده‌ها به تفکیک ارز محاسبه می‌شود؛ هیچ دو ارزی بدون نرخ تبدیل با هم جمع نمی‌شوند.
- **سازگاری:** ارز معاملات قدیمی که احتمالاً از فهرست حذف شده باشد، هنگام شروع مجدداً به فهرست ارزها افزوده می‌شود. رکوردهای بدون ارز AFN فرض می‌شوند.
- **ظاهر:** یادداشت‌های توضیحیِ اضافیِ روزنامچه حذف شده‌اند، منوی + پایین موبایل باقی مانده، واترمارک یاسر عفیف و لینک https://afifweb.vercel.app/ حفظ شده است.
- **عدد و تاریخ:** ورود ارقام فارسی و انگلیسی، نمایش عدد انگلیسی با جداکنندهٔ هزارگان و نمایش تاریخ شمسی افغانستان پشتیبانی می‌شود.

## راه‌اندازی

۱. **قبل از هر چیز** در نسخهٔ فعلی از مسیر تنظیمات، یک نسخهٔ پشتیبان JSON تهیه و در محل امنی ذخیره کنید.
۲. فایل‌های داخل این ZIP را به‌جای فایل‌های نسخهٔ قبلی در همان مخزن GitHub Pages قرار دهید؛ نشانی پروژه و محل ذخیرهٔ داده‌ها تغییر نمی‌کند.
۳. بعد از انتشار، برنامه را یک بار کاملاً ببندید و دوباره باز کنید. نسخهٔ service worker به v9 تغییر داده شده است.
۴. با داده‌های آزمایشی، یک حساب و دو ارز و یک معاملهٔ درک را امتحان کنید؛ سپس اطلاعات اصلی را به کار ببرید.

**محدودیت:** اطلاعات فقط در مرورگر همان دستگاه ذخیره می‌شوند. همگام‌سازی آنلاین یا تبدیل نرخ ارز در این نسخه وجود ندارد. پاک‌کردن داده‌های مرورگر یا استفاده از یک دامنهٔ متفاوت ممکن است باعث شود اطلاعات قبلی در سایت جدید دیده نشوند.

**بررسی:** کد JS از نظر نحو و تعاملات اصلی با Chromium آزمایش شده؛ نمایش و رفتار مخصوص Safari/iOS نیاز به بررسی روی آیفون واقعی دارد.

دفتر حساب‌کت نسخه ۲

امکانات:
- ثبت قرض/خرید جدید برای مشتری
- ثبت پرداخت مشتری و کم‌شدن آن از بدهکاری
- نمایش باقی بدهی، تصفیه‌شدن حساب یا طلب مشتری در صورت پرداخت اضافه
- خلاصه حساب جداگانه برای هر مشتری
- حذف معامله و محاسبه دوباره باقی حساب
- جست‌وجوی مشتری و معاملات
- خروجی Excel و CSV، نسخه پشتیبان و بازیابی
- سازگار با اطلاعات نسخه قبلی: رکوردهای قدیمی به عنوان قرض/خرید خوانده می‌شوند.

به‌روزرسانی GitHub Pages:
1. پیش از تغییر، در نسخه فعلی از «گرفتن نسخه پشتیبان» استفاده کنید.
2. فایل‌های داخل این ZIP را در ریشه همان مخزن GitHub آپلود کنید و نسخه‌های قبلی را جایگزین کنید؛ به‌ویژه index.html و sw.js.
3. Commit changes بزنید و 1 تا 5 دقیقه صبر کنید.
4. سایت را در Safari باز کنید. اگر نسخه قدیمی دیده شد، صفحه را تازه‌سازی کنید یا Safari را ببندید و دوباره باز کنید.

اطلاعات در حافظه محلی مرورگر همان دستگاه ذخیره می‌شود؛ این سایت به‌تنهایی اطلاعات را بین دستگاه‌ها همگام نمی‌کند. نسخه پشتیبان بگیرید.
